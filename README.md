# cdp
[CDP] CudaPilot

CudaPilot is a header-only data generation and model validation suite created for AeroMed Labs Inc. This suite is programmed in C++/CUDA, and includes a Vulkan based DearImGUI interface that can render a simulated physics environment built using voxels. All rendering, data generation, and model validation is performed on the GPU using CUDA, while the CPU is used to direct execution flow and accept user input.
